How to label
  1. Scan all three panels. A South Atlantic Anomaly pass shows as a raised region — it is often much clearer in ddsi or ddsi×hardness than in flux, so check every panel before deciding.
  2. Click anywhere in a panel where the pass begins.
  3. Click again where it ends.
  4. Drag either edge to fine-tune, then press Save label.
  5. Repeat for every pass you can see, then Mark day complete.

Scroll to zoom, shift-drag to pan, Esc clears a selection. All times are UTC. There are typically around 11 passes per day, but some are too weak to see — only label what you can actually identify. Missing an invisible pass is expected and is not an error.
